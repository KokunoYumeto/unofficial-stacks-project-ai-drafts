## Reproduction

Extract the complete source ZIP and run `python build.py --validate-only`. With pdfLaTeX, XeLaTeX, BibTeX, Python pypdf, and the Cambria, Cambria Math and Segoe UI Symbol fonts available, run `python build.py --output /absolute/path/to/new-build-directory`. The destination must be new. The Windows process guard and shared TeX mutex prevent overlapping engines. Fonts are dependencies and are not redistributed. The builder retains prior chapters and two fresh corrected sets, compares PDF and auxiliary bytes at a fixed point, and reports diagnostics. The reference adapter supplies exact source tags and pinned links; cited authorities are included.
