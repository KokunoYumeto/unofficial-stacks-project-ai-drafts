## 1. The set of objects needed for a calculation

Original 8352–8366 invokes current Sets, lemma-abelian-injectives,
1135–1157. That lemma includes more than an exact embedding of a
small abelian category: it requires its injective objects to be exactly
the objects that are injective in the ambient category. This is the
property needed to compare the resulting resolutions.

Here is the construction in the usual locally small big-category setting
of that statement. Start with the given set of objects and, when a set
of diagrams is specified, every object occurring in those diagrams.
Inductively enlarge a set S\_n of objects to a set S\_{n+1} containing:
the zero object and chosen finite biproducts of objects of S\_n; chosen
kernels and cokernels of every morphism between objects of S\_n; a
chosen monomorphism X->J\_X with J\_X injective for every X in S\_n;
and witnesses to noninjectivity for every X in S\_n that is not
injective in the ambient category. Such a witness consists of a
monomorphism U\_X->V\_X and a map U\_X->X admitting no extension
V\_X->X; include U\_X and V\_X. Each stage has a set of requests:
the category is locally small, there are a set of pairs of existing
objects, and each witness involves finitely many objects and maps.
Set-indexed collection and choice make the enlargement a set.
This does not select data simultaneously for every object of the
proper class.

Let A' be the full subcategory on the union of the S\_n. It is
additive and has kernels and cokernels computed in A, because
every finite collection of its objects appears at one stage.
The comparison from coimage to image is the ambient isomorphism,
so A' is abelian and its inclusion is exact. Every object X
embeds in its J\_X within A', hence A' has enough injectives.
An ambient injective in A' is injective there: all monomorphisms
of A' remain monic in A, and fullness includes the ambient
extensions. Conversely a noninjective X in A' has its chosen
witness in a later stage of A', so is not injective in A'.
This proves the additional injectivity property rather than
assuming that exactness of an embedding alone would imply it.

For a set of filtered complexes, include all their terms, all their
filtration subobjects, and the objects in their specified diagrams
in S\_0. There are only set many: the degrees and filtration indices
are integers. Each such diagram is then a diagram in A'. A
filtered injective resolution formed there is also one in A,
since its graded injectives are ambient injectives. The homotopy
Hom groups between these complexes agree by fullness. Computing
bounded-below filtered derived Hom by these resolutions therefore
proves that the inclusion on these derived objects is fully
faithful and computes the same maps. The analogous argument
without filtrations proves the bounded-below unfiltered comparison.
Given two such choices of A', apply the same construction to
the union of their object sets; the resulting comparison uses
the same ambient Hom groups. This proves compatibility of
the calculations and does not assert a quasi-inverse selected
on the entire proper class.

The remark's “only if” refers to its preceding use of ordinary
choice to pick representatives for a set of objects. It is not
used here as an impossibility theorem about every big category.
For example, PART11 supplies an explicit functorial construction
on a fixed filtration window when functorial embeddings are
given. No new source defect is counted from that reading of
the remark. RECON-063 / DERIVED-058 reconciles the existing
MC-STK-ERR-0869 possessive correction at 8364.
